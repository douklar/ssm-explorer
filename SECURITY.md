# Security Policy

## Supported Versions

The following versions of SSM Explorer are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of SSM Explorer and the Douklar DevOps Tools suite very seriously. If you find a security vulnerability, please report it immediately.

### How to Report

Please do **not** open a public GitHub issue for security vulnerabilities. Instead, send your report via email to **github@hummatovic.com**.

To help us process and resolve the issue quickly, please include:
- A detailed description of the vulnerability.
- Clear, step-by-step instructions to reproduce the issue.
- Potential impact or proof-of-concept (PoC) code if applicable.

### What to Expect

- **Acknowledgment**: You will receive an initial email acknowledgment of your report within 48 hours.
- **Updates**: We will provide status updates at least once every 7 days while we investigate and resolve the issue.
- **Resolution**: If the vulnerability is confirmed, we will coordinate a fix and release a patched version (e.g., `1.0.1`) as quickly as possible.
